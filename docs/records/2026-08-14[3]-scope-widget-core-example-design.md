# Example для `ScopeWidgetCore`

> **Состояние на 2026-08-14:** дизайн согласован, реализация не начата.
> **Что это:** дизайн второго блока вкладки `ScopeWidget`, показывающего
> изменяемое состояние в собственном элементе и точечные уведомления.
> **Связанные записи:** `2026-08-14[4]-scope-widget-core-example-plan.md`,
> `2026-08-13[2]-docs-and-toolchain-report.md`.

## Цель

Дополнить `example/scopo_demo` исполнимым примером прямого использования
`ScopeWidgetCore`. Существующий блок `ScopeWidgetBase` остаётся на месте:
вкладка должна показывать рядом два уровня семейства — неизменяемые параметры
виджета и изменяемое состояние собственного элемента.

## Устройство

В каталог `home/demos/a_scope_widget/` добавляется
`scope_widget_core_example.dart` с пятью ролями:

- `ScopeWidgetCoreExample` устанавливает новый `CounterScope`;
- `CounterScope` наследует
  `ScopeWidgetCore<CounterScope, CounterScopeElement>`, создаёт элемент и
  открывает статические `of` и `countOf`;
- `CounterScopeContext` — узкий интерфейс для команд: текущее значение и
  `increment()` без выдачи вызывающему коду конкретного элемента;
- `CounterScopeElement` хранит счётчик, увеличивает его и вызывает
  `notifyDependents()`, а `buildChild()` делегирует UI виджету скоупа;
- отдельные потомки читают счётчик через `countOf` и вызывают команду через
  `of`.

Счётчик начинается с нуля. Нажатие кнопки синхронно увеличивает его на единицу;
ошибочных и асинхронных веток у сценария нет.

## Визуальное поведение

`ScopeWidgetDemo` становится колонкой из двух одинаковых по высоте блоков с
`Divider`: существующий `ScopeWidgetExample` сверху, новый
`ScopeWidgetCoreExample` снизу.

Новый блок повторяет визуальный язык остальных примеров. Внешний
`BlinkingBox` окружает неизменяемое поддерево скоупа, внутренний — зависимый
текст счётчика. После `notifyDependents()` внутренний блок мигает, а внешний
нет: demo наглядно показывает, что селектор перестроил зависимого, не всё
поддерево.

## Проверка

В `example/scopo_demo/test/scope_widget_core_example_test.dart` widget-тест
устанавливает `ScopeWidgetCoreExample`, видит начальный `0`, нажимает кнопку и
видит `1`. Он проверяет, что публичный путь примера собран целиком: поиск,
команда элемента, `notifyDependents` и селектор.

Перед завершением проходят этот тест, analyzer `example/scopo_demo` и все семь
проверок из `AGENTS.md` §6. Пункт `example` для `ScopeWidgetCore` удаляется из
бэклога в коммите результата; будущая документация example-кода остаётся.
